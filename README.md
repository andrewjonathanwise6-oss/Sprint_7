
# Sprint_7 — API Tests

Автоматизированные API-тесты сервиса Яндекс Самокат.

## Используемые технологии

- Python
- Pytest
- Requests
- Allure

## Покрытие

- Создание курьера
- Авторизация курьера
- Создание заказа с разными вариантами цвета
- Получение списка заказов

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m pytest -v --tb=short
```

## Генерация Allure Results

```bash
python -m pytest --alluredir=target/allure-results
```

## Просмотр отчёта

```bash
allure serve target/allure-results
```

## Известная проблема API

При авторизации курьера без обязательного поля `password` сервер не возвращает ожидаемый HTTP 400. Наблюдаются тайм-ауты и HTTP 504.

Тест сохранён в проекте.
